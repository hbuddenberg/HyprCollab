Hey, my waybar is not showing the workspaces module on workspace 2. It only displays when I switch to it. How can I fix this in hyprland.conf?
╰ ╯
╭─ 🎨 Luna ─ 18:13 ╮
This happens because Waybar workspaces modules dynamically render active/existing workspaces. To force Waybar to show them even when empty, you must configure them in your hyprland.conf and update Waybar's settings. First, let's look at your active monitor outputs:
╭─ ▸ Tool: shell_command("hyprctl monitors") [Click to expand] ╮
✓ Exit code: 0
├─ stdout ┤
Monitor eDP-1 (ID 0): 1920x1080@144.00Hz at 0x0 active workspace: 1 (1) special workspace: 0 ()
╰ ╯
Add this rules block to your config:
┌─ Config ─ ~/.config/hypr/hyprland.conf ┐
1# Persistent Workspaces Rules 2workspace = 1, persistent:true 3workspace = 2, persistent:true 4workspace = 3, persistent:true
└ ┘
Additionally, update your Waybar config.jsonc workspace settings to match:
┌─ JSONC ─ config.jsonc ┐
1// Waybar Workspaces Config 2"hyprland/workspaces": { 3 "format": "{name}", 4 "on-click": "activate", 5 "persistent-workspaces": { 6 "*": 3 7 } 8}
