▌ You 18:12
Hey, my waybar is not showing the workspaces module on workspace 2. It only displays when I switch to it. How can I fix this in hyprland.conf?
▌ HyprCollab 🤖 Dev Agent 18:13
This happens when workspace 2 is dynamically created and destroyed when empty. To make workspaces persistent, you should define them with workspace rules in your `hyprland.conf` file. Let's inspect the active monitors list to verify workspace mapping.
╭─ tool: shell_command ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────── [Click to expand] ╮
│
hyprctl monitors
│
│
Monitor eDP-1 (ID 0): 1920x1080@144.00301Hz at 0x0 active workspace: 1 (1) special workspace: 0 () reserved: [0, 30, 0, 0]
│
╰ ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────── ╯
Modify your config file to declare workspaces persistent:
╭─ ~/.config/hypr/hyprland.conf ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────── ╮
│
1# Persistent Workspaces Rules 2workspace = 1, persistent:true 3workspace = 2, persistent:true 4workspace = 3, persistent:true
│
